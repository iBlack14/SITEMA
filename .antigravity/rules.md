# Project UI/UX Rules

Usa siempre las siguientes skills de diseño para cualquier modificación de interfaz:

1. **UI-UX-PRO-MAX** ([SKILL.md](skills/ui-ux-pro-max/SKILL.md)): Para inteligencia de diseño, paletas de colores, tipografía y mejores prácticas de componentes.
2. **Impeccable** ([SKILL.md](skills/impeccable/SKILL.md)): Para pulido visual, accesibilidad y evitar el "AI slop".

## Principios Críticos:
- **Accesibilidad**: Contraste 4.5:1 mínimo. Objetivos de toque >= 44x44pt.
- **Consistencia**: Ritmo de espaciado de 8dp.
- **Aislamiento**: Cada componente debe ser autocontenido y seguir el sistema de diseño MASTER.
- **Sin placeholders**: Usa siempre imágenes reales o generadas.

Cualquier cambio en `seguimiento.html` o el dashboard debe ser auditado con `/impeccable audit` (mentalmente) antes de ser entregado.
